# Resultados de aprendizaje

Al finalizar el curso, el estudiante estará en capacidad de:

1. Explicar la relación funcional entre hardware, sistema operativo, sistema de
   archivos, procesos, intérprete de Python y entornos de ejecución.
2. Utilizar una terminal Linux para organizar archivos, buscar información,
   combinar comandos y automatizar tareas sencillas con Bash.
3. Emplear Git y GitHub para registrar cambios, recuperar versiones, colaborar y
   documentar un trabajo computacional.
4. Descomponer un problema físico en entradas, supuestos, operaciones,
   algoritmos, resultados y criterios de validación.
5. Leer, explicar y escribir programas en Python que utilicen tipos básicos,
   estructuras de control, colecciones, funciones, archivos, excepciones y
   módulos.
6. Depurar y verificar programas mediante mensajes de error, trazas, casos
   límite, pruebas automatizadas y comprobaciones físicas.
7. Reconocer efectos de punto flotante, discretización, convergencia, unidades e
   incertidumbre en un resultado computacional.
8. Elegir entre Python nativo, NumPy y Pandas de acuerdo con la estructura del
   problema y de los datos.
9. Procesar arreglos y datos tabulares, y comunicar resultados mediante figuras
   científicas creadas con la interfaz orientada a objetos de Matplotlib.
10. Formular, desarrollar, reproducir y defender un proyecto computacional con
    una pregunta física no trivial y evidencia de validación.
11. Evaluar críticamente código y explicaciones producidos por IA, declarar su
    uso y conservar responsabilidad intelectual sobre el resultado.

Clases y objetos, herencia, SciPy y SymPy se ofrecen como extensiones si el tiempo
lo permite; no son resultados obligatorios en el calendario de reanudación.

## Principios del curso

- La corrección científica tiene prioridad sobre la sofisticación sintáctica.
- Un programa no se considera correcto solo porque se ejecuta.
- La simplicidad justificada vale más que la complejidad ornamental.
- Todo resultado importante debe poder verificarse y reproducirse.
- Consultar documentación es una competencia; delegar la comprensión no lo es.
