# Política de inteligencia artificial

## Propósito

El curso reconoce que la IA es una herramienta profesional real, pero distingue
entre aprender con una herramienta y reemplazar la construcción de competencia.
Todo estudiante debe demostrar que puede programar, leer y verificar código sin
asistencia generativa.

La política institucional de la Universidad prevalece sobre este documento.

## Niveles de uso

Cada actividad indicará uno de estos niveles:

### Nivel 0 — Evaluación protegida

No se permite IA generativa, autocompletado generativo, comunicación externa ni
soluciones preparadas. Aplica a parciales, evaluación integradora, ejercicios de
salida y sustentaciones.

### Nivel 1 — Recursos convencionales

Se permiten notas, documentación oficial, buscadores y discusión delimitada, pero
no generación automática de código o texto. Es el nivel predeterminado para los
laboratorios 1 a 4.

### Nivel 2 — IA como crítica declarada

Se permite pedir explicaciones, alternativas, casos de prueba o revisión de código
escrito primero por el estudiante. No se permite presentar una implementación
generada como propia. Toda interacción relevante se registra.

### Nivel 3 — Colaboración humano-IA estudiada

La actividad exige experimentar con IA o agentes. Se evalúa la capacidad de
especificar, inspeccionar cambios, ejecutar pruebas, detectar errores y aceptar o
rechazar propuestas con argumentos.

## Declaración obligatoria

Cuando una actividad admita niveles 2 o 3, se entregará `AI_USAGE.md` indicando:

- herramienta y versión o servicio, si se conoce;
- fecha y finalidad de cada interacción relevante;
- prompt o resumen fiel de la solicitud;
- archivos o secciones afectadas;
- errores encontrados en la respuesta;
- decisiones aceptadas y rechazadas;
- validaciones realizadas por el estudiante.

Declarar el uso no reduce la nota. Ocultarlo impide autenticar el trabajo y se
tramitará de acuerdo con las normas institucionales.

## Responsabilidad

El estudiante conserva responsabilidad por:

- exactitud científica y numérica;
- licencias, privacidad y procedencia de datos;
- funcionamiento y seguridad del código;
- citas y atribuciones;
- capacidad de explicar y modificar todo lo entregado.

No se usarán detectores automáticos de IA como única evidencia de una falta. La
autenticidad se establecerá principalmente mediante proceso, historial, pruebas,
preguntas específicas y desempeño individual.
