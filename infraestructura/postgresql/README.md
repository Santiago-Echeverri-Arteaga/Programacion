# Material PostgreSQL

Ejemplos para aprender primero SQL puro y luego conectar Python.

- [`init/`](init/README.md): esquema y datos que PostgreSQL carga al crear un
  volumen vacío.
- `consultas_guiadas.sql`: selección, filtros, agregaciones, uniones y revisión de
  planes.

Ejecute las consultas con `psql` antes de trasladarlas a Python. Las credenciales
de demostración son exclusivamente locales y no deben reutilizarse en servicios
reales.
