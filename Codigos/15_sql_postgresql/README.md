# SQL y PostgreSQL

Ejemplos para las clases 40 y 41.

- `conexion_postgresql.py`: Psycopg, parámetros y administradores de contexto.
- `conexion_postgresql_pandas.py`: SQLAlchemy y carga controlada en Pandas.

El esquema, datos y consultas SQL puras se encuentran en
[`infraestructura/postgresql/`](../../infraestructura/postgresql/README.md). Las credenciales se reciben mediante
`DATABASE_URL`; nunca se escriben en estos archivos.
