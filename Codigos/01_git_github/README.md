# Git y GitHub

Material para la clase 5 y el laboratorio 1.

- `generar_datos.sh` crea un archivo pequeño cuyo cambio puede seguirse con Git.
- `secuencia_comandos.md` describe un ciclo de trabajo local y remoto.

El ejemplo permite observar por separado directorio de trabajo, área de
preparación, commit y remoto. No se ejecuta automáticamente `git push`.
