# Sistema, Linux y Bash

Ejemplos para las clases 1–4.

- `inspeccionar_entorno.sh`: ejecuta una secuencia corta para reconocer el entorno.
- `tuberias_mediciones.sh`: muestra `grep`, una tubería y redirecciones sobre un CSV.

Se estudian rutas, procesos, entrada/salida, códigos de retorno, tuberías y
scripts reproducibles. Los comandos se ejecutan primero línea por línea y después
como script.

Estos archivos no usan variables, condicionales ni ciclos. Las técnicas de Bash
para scripts robustos se posponen hasta que el estudiante conozca control de flujo.
