# Sistema, Linux y Bash

Ejemplos para las primeras clases de la reanudación.

- [`../../clases/clase_02_sistema_operativo/demo_entorno.py`](../../clases/clase_02_sistema_operativo/demo_entorno.py): reconoce el entorno desde Python.
- [`../../clases/clase_03_terminal_linux/demo_terminal.md`](../../clases/clase_03_terminal_linux/demo_terminal.md): secuencia comentada de navegación.
- [`../../laboratorios/lab01_estacion_reproducible/demo_filtrar_temperaturas.sh`](../../laboratorios/lab01_estacion_reproducible/demo_filtrar_temperaturas.sh): muestra `grep` y una tubería.
- [`../../laboratorios/lab01_estacion_reproducible/demo_contar_temperaturas.sh`](../../laboratorios/lab01_estacion_reproducible/demo_contar_temperaturas.sh): muestra cómo un script ejecutable llama a otro.

Se estudian rutas, procesos, entrada/salida, códigos de retorno, tuberías y
scripts reproducibles. Los comandos se ejecutan primero línea por línea y después
como script.

Los scripts Bash no usan variables, condicionales ni ciclos. Las técnicas de Bash
para scripts robustos se posponen hasta que el estudiante conozca control de flujo.
