# Paquete de demostración `fisica_utils`

Paquete mínimo usado en la clase 16 para mostrar `__init__.py`, importaciones y
separación entre módulo reutilizable y programa cliente.

- `mecanica.py`: funciones del dominio.
- `__init__.py`: interfaz pública del paquete.

No se propone como arquitectura obligatoria para todos los ejercicios.
