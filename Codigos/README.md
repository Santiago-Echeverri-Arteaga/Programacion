# Códigos de ejemplo

Esta carpeta contiene exclusivamente ejemplos desarrollados en clase. No contiene
soluciones de laboratorios ni proyectos completos. Cada subcarpeta corresponde a
un tema del curso, explica sus archivos y señala las clases donde se utiliza.

| Carpeta | Tema | Clases principales |
|---|---|---|
| `00_sistema_linux_bash/` | Sistema operativo, terminal y Bash | 1–4 |
| `01_git_github/` | Git, GitHub y trazabilidad | 5 |
| `02_python_basico/` | Tipos, operaciones y primeros programas | 7–9 |
| `03_control_flujo/` | Condicionales, ciclos y acumulación | 10–11 |
| `04_colecciones_cadenas/` | Cadenas y colecciones | 12 |
| `05_funciones/` | Funciones, argumentos y documentación | 9 y 19 |
| `06_archivos_excepciones/` | Archivos, rutas, excepciones y depuración | 13 |
| `07_modulos_entornos/` | Módulos, paquetes y dependencias | 16 |
| `08_pruebas_algoritmos/` | Pruebas, complejidad y error numérico | 20–21 |
| `09_poo/` | Clases, composición y polimorfismo | 22–25 |
| `10_numpy/` | Arreglos y vectorización | 27–28 |
| `11_matplotlib/` | Visualización científica | 29 |
| `12_scipy_sympy/` | Herramientas científicas focalizadas | 31 |
| `13_pandas/` | Datos tabulares y limpieza | 34–36 |
| `14_ia_agentes/` | Auditoría de código generado | 39 |
| `15_sql_postgresql/` | PostgreSQL y clientes Python | 40–41 |
| `16_docker/` | Imágenes y contenedores mínimos | 42 |

## Convenciones

- Los ejemplos se ejecutan desde la raíz del repositorio salvo indicación.
- Las magnitudes físicas incluyen unidades en nombres o documentación.
- Los archivos deliberadamente defectuosos lo indican en su encabezado.
- Ningún archivo debe contener contraseñas o datos personales.
- Los resultados regenerables se guardan en `resultados/`.
