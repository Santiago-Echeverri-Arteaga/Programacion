# SciPy y SymPy

Ejemplos para la clase 34.

- `ajuste_lineal.py`: ajuste con incertidumbre usando SciPy.
- `verificar_oscilador.py`: comprobación simbólica de una ecuación diferencial.

El objetivo es aprender a leer una API científica y validar su salida, no cubrir
por completo ambas bibliotecas.
