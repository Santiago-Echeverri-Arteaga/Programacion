# Funciones

Ejemplos para las clases 9 y 19.

- `conversiones.py`: funciones pequeñas con contratos y unidades.
- `argumentos.py`: parámetros posicionales, nominales, `*args` y `**kwargs`.
- `temporizador.py`: decorador breve para lectura, no como patrón obligatorio.

Se priorizan responsabilidades claras y valores de retorno verificables.
