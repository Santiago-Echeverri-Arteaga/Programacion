# Laboratorios

Los seis laboratorios forman una secuencia acumulativa. Cada directorio contiene
un enunciado y, cuando es pertinente, archivos iniciales. Las soluciones se
mantienen en el repositorio docente privado.

| Laboratorio | Tema | IA |
|---:|---|---|
| 1 | Linux, Bash, Git y reproducibilidad | Nivel 1 |
| 2 | Fundamentos y archivos con Python nativo | Nivel 1 |
| 3 | Modelo físico modular y verificable | Nivel 1 |
| 4 | NumPy, azar y Matplotlib OO | Nivel 1 |
| 5 | Pandas y datos experimentales imperfectos | Nivel 1 |
| 6 | PostgreSQL, Python y Docker | Nivel 2 declarado |

## Entrega común

- repositorio o directorio con estructura solicitada;
- instrucciones de ejecución;
- evidencia de pruebas o comprobaciones;
- respuestas breves a las preguntas físicas;
- ejercicio de salida individual realizado en clase.

La rúbrica común está en [`../programa/evaluacion.md`](../programa/evaluacion.md).
