# Clase 27 — NumPy: arreglos, forma, tipo e indexación

## Propósitos

- explicar la diferencia entre lista y arreglo homogéneo;
- inspeccionar `shape`, `ndim`, `size` y `dtype`;
- seleccionar datos con índices, rebanadas y máscaras.

## Preparación

Ejecutar [`arreglos.py`](arreglos.py) y usar
[`arreglos_guiados.ipynb`](arreglos_guiados.ipynb) para predecir la forma de cada
resultado antes de revelar la salida.

## Secuencia (120 min)

1. Motivación y modelo de datos (20 min).
2. Construcción, forma y tipo (30 min).
3. Indexación, rebanadas y máscaras (30 min).
4. Práctica con series físicas (25 min).
5. Ejercicio de salida (15 min).
