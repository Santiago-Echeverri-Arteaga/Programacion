# Clase 22 — Clases y objetos

## Propósitos

- modelar estado y comportamiento relacionados;
- distinguir clase, instancia, atributo y método;
- mantener invariantes desde el constructor.

## Preparación

Leer [`particula.py`](particula.py) y decidir qué estados serían físicamente
inválidos.

## Secuencia (120 min)

1. De registros sueltos a objetos (20 min).
2. Constructor, estado y métodos (30 min).
3. Invariantes y representación (25 min).
4. Modelado en parejas (30 min).
5. Ejercicio de salida (15 min).

## Evidencia

Diagrama simple y clase pequeña cuyo uso tenga una ventaja clara sobre funciones
aisladas.
