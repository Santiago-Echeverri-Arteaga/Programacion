# Clase 43 — Laboratorio 6 integrador

## Propósito

Integrar SQL puro, PostgreSQL, Python y Docker en un flujo reproducible con una
pregunta científica y validaciones explícitas.

## Antes de la sesión

Leer la [guía completa](../../laboratorios/lab06_postgres_docker/README.md),
construir las imágenes y verificar que no haya credenciales versionadas.

## Secuencia (120 min)

1. Control individual de arquitectura y SQL (15 min).
2. Inicialización y consulta desde `psql` (25 min).
3. Consulta parametrizada desde Python (25 min).
4. Resultado científico, prueba desde cero y diagnóstico (40 min).
5. Ejercicio de salida individual (15 min).

## Material

[`verificar_stack.py`](verificar_stack.py) revisa archivos y secretos obvios; no
garantiza corrección, seguridad ni reproducibilidad completa.
