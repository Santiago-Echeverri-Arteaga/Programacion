# Clase 19 — Funciones avanzadas, tipos y documentación

## Propósitos

- usar valores predeterminados, argumentos nombrados, `*args` y `**kwargs` con criterio;
- reconocer funciones como objetos;
- escribir anotaciones y documentación que aclaren el contrato.

## Preparación

Leer [`calibracion.py`](calibracion.py) e identificar qué argumentos deberían ser
posicionales y cuáles nombrados.

## Secuencia (120 min)

1. Repaso de alcance y objetos función (20 min).
2. Firmas expresivas y argumentos variables (30 min).
3. Anotaciones, docstrings y contratos (25 min).
4. Refactorización guiada (30 min).
5. Ejercicio de salida (15 min).

## Evidencia

Función documentada y tres llamadas justificadas, incluida una que deba fallar.
