# Clase 09 — Funciones, contratos y descomposición

## Propósitos

- diseñar funciones pequeñas con entrada, salida y propósito explícitos;
- diferenciar `return` de `print`;
- expresar precondiciones, unidades y casos límite.

## Preparación

Leer [`cinematica.py`](cinematica.py) y formular un caso normal y uno límite para
cada función.

## Secuencia (120 min)

1. Del problema físico al contrato (25 min).
2. Parámetros, retorno, alcance y documentación (30 min).
3. Implementación por parejas (35 min).
4. Pruebas manuales y revisión cruzada (20 min).
5. Cierre individual (10 min).

## Evidencia

Una función nueva con docstring, unidades, dos ejemplos y justificación del caso
límite escogido.
