# Clase 18 — Parcial 1 escrito

## Alcance público

Evaluación individual en papel sobre lectura, trazado, escritura y depuración de
Python básico, además de Linux, Git y reproducibilidad. No se permite IA, equipo
electrónico ni material no autorizado.

## Secuencia

1. Organización, instrucciones y declaración de integridad (10 min).
2. Parcial escrito (90 min).
3. Recolección y cierre metacognitivo sin calificación (20 min).

## Material de preparación

[`fragmentos_practica.py`](fragmentos_practica.py) ilustra el tipo de lectura que
se espera, pero no reproduce preguntas del examen. El banco, la clave y la rúbrica
analítica permanecen en `_docente_privado/`.
