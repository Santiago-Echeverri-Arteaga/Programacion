# Práctica — navegación y rutas

1. Cree un árbol con carpetas `datos/raw`, `datos/processed` y `resultados`.
2. Desde la raíz del árbol, escriba una ruta relativa y una absoluta para el mismo
   archivo.
3. Copie un archivo a `processed` y muévalo luego a `resultados`.
4. Consulte `--help` para descubrir cómo mostrar archivos ocultos con `ls`.
5. Explique el efecto de `.`, `..` y del directorio de trabajo en cada orden.
