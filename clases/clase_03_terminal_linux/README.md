# Clase 03 — Terminal Linux: rutas, navegación y ayuda

- Semana: 1. Duración: 120 minutos. IA: nivel 1.
- Material: `rutas_y_ayuda.sh` y un árbol de archivos preparado.

## Resultados

- Construir e interpretar rutas absolutas y relativas.
- Navegar sin perder de vista el directorio de trabajo.
- Consultar `man`, `--help` y códigos de salida.

## Secuencia

| Minutos | Actividad |
|---:|---|
| 0–15 | Predicción sobre cinco rutas |
| 15–35 | `pwd`, `ls`, `cd`, `.`, `..` y nombres con espacios |
| 35–55 | Crear, copiar y mover archivos en un directorio seguro |
| 55–65 | Pausa |
| 65–85 | Ayuda y lectura de sintaxis de comandos |
| 85–108 | Búsqueda del tesoro en parejas |
| 108–120 | Salida: resolver una ruta sin usar la terminal |

## Contingencia

Si falla la sala, la búsqueda se realiza sobre un árbol impreso y conserva el
objetivo conceptual.
