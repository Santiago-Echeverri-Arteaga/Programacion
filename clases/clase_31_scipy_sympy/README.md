# Clase 31 — SciPy y SymPy seleccionados

## Propósitos

- distinguir cálculo simbólico de cálculo numérico;
- seleccionar una herramienta existente sin ocultar supuestos;
- verificar el resultado contra un caso conocido.

## Preparación

Leer [`herramientas.py`](herramientas.py) e identificar entradas, salidas y criterio
de validación de cada ejemplo.

## Secuencia (120 min)

1. Mapa de problemas y librerías (20 min).
2. SymPy: expresión, sustitución y derivación (25 min).
3. SciPy: ajuste o búsqueda de raíces (30 min).
4. Verificación, supuestos y documentación (30 min).
5. Cierre individual (15 min).

## Evidencia

Un resultado simbólico y uno numérico con verificación independiente. No se
desarrollan aquí los algoritmos que corresponden a Métodos Numéricos.
