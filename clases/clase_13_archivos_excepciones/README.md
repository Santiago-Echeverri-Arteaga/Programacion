# Clase 13 — Archivos, rutas, excepciones y depuración

## Propósitos

- manejar rutas con `pathlib` y archivos con `with`;
- validar estructura y contenido de datos;
- capturar solamente errores que puedan tratarse con sentido.

## Preparación

Revisar [`leer_mediciones.py`](leer_mediciones.py) y
[`mediciones.csv`](mediciones.csv).

## Secuencia (120 min)

1. Rutas reproducibles y codificación (20 min).
2. Lectura segura y contexto `with` (20 min).
3. Excepciones específicas y mensajes útiles (30 min).
4. Sesión de depuración con datos defectuosos (35 min).
5. Ejercicio individual (15 min).

## Evidencia

Programa que informa línea y causa de un dato inválido, más una explicación de
por qué no se empleó `except Exception`.
