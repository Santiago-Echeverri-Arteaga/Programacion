# Clase 21 — Algoritmos, eficiencia y error numérico

## Propósitos

- describir un algoritmo antes de implementarlo;
- comparar corrección, legibilidad y costo;
- reconocer cancelación, redondeo y acumulación de error.

## Preparación

Ejecutar [`sumas.py`](sumas.py) y explicar por qué cambia el resultado.

## Secuencia (120 min)

1. Algoritmo, corrección y tamaño de entrada (25 min).
2. Conteo cualitativo de operaciones (20 min).
3. Representación finita y suma numérica (30 min).
4. Experimento computacional y discusión (30 min).
5. Cierre individual (15 min).

## Evidencia

Predicción, medición y explicación de una diferencia numérica, sin confundirla
con incertidumbre experimental.
