# Práctica — estados de Git

En un repositorio de prueba:

1. Cree un archivo pequeño y prediga `git status` antes de ejecutarlo.
2. Compare `git diff` antes y después de `git add`.
3. Cree un commit con un mensaje que explique la intención del cambio.
4. Modifique una línea y compare directorio de trabajo, *stage* y `HEAD`.
5. Publique en un remoto vacío y explique qué existe localmente antes del
   primer `push`.

No se usan ramas adicionales, `merge`, `rebase` ni reescritura del historial.
