# Material del 1 de septiembre — Git y GitHub básico

- Fecha: martes 1 de septiembre de 2026. Duración: 120 minutos. IA: nivel 1.
- Material: secuencia y script de datos en
  [`../../Codigos/01_git_github/`](../../Codigos/01_git_github/README.md).

## Resultados

- Distinguir trabajo, `stage`, commit local y remoto.
- Leer `status`, `diff` e historial antes de modificar.
- Crear commits pequeños con intención científica.

## Secuencia

| Minutos | Actividad |
|---:|---|
| 0–20 | Ordenar tarjetas del modelo de estados |
| 20–40 | Demostración local: cambio, diff, add y commit |
| 40–55 | Historial y diferencia entre commit local y remoto |
| 55–65 | Pausa |
| 65–85 | GitHub, remotos, colaboración y credenciales |
| 85–110 | Publicación básica y verificación en GitHub |
| 110–120 | Salida: interpretar `git status` |

## Evidencia

Se evalúa coherencia y capacidad de explicar los cambios, no la cantidad de
commits.

Ramas adicionales, conflictos, `merge`, `rebase` y reescritura de historial
quedan fuera de este primer bloque.
