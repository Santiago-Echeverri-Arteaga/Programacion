# Clase 05 — Git, GitHub y reproducibilidad

- Semana: 2. Duración: 120 minutos. IA: nivel 1.
- Material: [`demo_git.sh`](demo_git.sh); ejemplos en
  [`../../Codigos/01_git_github/`](../../Codigos/01_git_github/README.md).

## Resultados

- Distinguir trabajo, `stage`, commit, rama y remoto.
- Leer `status`, `diff` e historial antes de modificar.
- Crear commits pequeños con intención científica.

## Secuencia

| Minutos | Actividad |
|---:|---|
| 0–20 | Ordenar tarjetas del modelo de estados |
| 20–40 | Demostración local: cambio, diff, add y commit |
| 40–55 | Historial, restauración conceptual y ramas |
| 55–65 | Pausa |
| 65–85 | GitHub, remotos, colaboración y credenciales |
| 85–110 | Conflicto preparado y resolución guiada |
| 110–120 | Salida: interpretar `git status` |

## Evidencia

Se evalúa coherencia y capacidad de explicar los cambios, no la cantidad de
commits.
