# Clase 40 — PostgreSQL desde SQL puro

## Propósitos

- distinguir servidor, base, esquema, tabla, fila y consulta;
- crear restricciones e insertar datos con SQL;
- consultar con filtros, agregaciones, uniones y planes básicos.

## Preparación

Levantar el servicio descrito en [`../../guias/14_postgresql.md`](../../guias/14_postgresql.md)
y abrir `psql`. Esta clase empieza en SQL, no en Python.

## Secuencia (120 min)

1. Modelo relacional y arquitectura cliente–servidor (20 min).
2. Recorrido guiado de `psql` (15 min).
3. DDL, restricciones e inserciones (25 min).
4. Consultas de [`consultas.sql`](consultas.sql) (40 min).
5. Ejercicio individual (20 min).

## Evidencia

Archivo `.sql` ejecutable desde una base limpia y explicación del resultado de
una unión y una agrupación.
