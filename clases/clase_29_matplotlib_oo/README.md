# Clase 29 — Matplotlib orientado a objetos

## Propósitos

- construir figuras con `fig` y `ax`;
- comunicar variables, unidades e incertidumbre;
- exportar una figura reproducible y legible.

## Preparación

Ejecutar [`figura.py`](figura.py), recorrer
[`figura_guiada.ipynb`](figura_guiada.ipynb) e identificar qué decisiones
pertenecen a datos y cuáles a presentación.

## Secuencia (120 min)

1. Anatomía de una figura científica (20 min).
2. API orientada a objetos (25 min).
3. Incertidumbre, leyenda y unidades (25 min).
4. Taller de crítica y rediseño (35 min).
5. Ejercicio de salida (15 min).

## Evidencia

Archivo PNG o PDF acompañado del script y un pie de figura que permita
interpretarlo sin depender del texto principal.
