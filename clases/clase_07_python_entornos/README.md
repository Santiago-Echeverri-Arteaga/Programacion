# Clase 07 — Python, scripts, notebooks y entornos

## Propósitos

- distinguir intérprete, script y notebook;
- crear y activar un entorno virtual;
- ejecutar un programa y leer un error básico.

## Preparación

Python 3.12+, terminal y editor. Revisar [`comparar_formatos.py`](comparar_formatos.py)
y [`comparar_script_notebook.ipynb`](comparar_script_notebook.ipynb).

## Secuencia (120 min)

1. Activación y diagnóstico del entorno (15 min).
2. Demostración: REPL, script y notebook (30 min).
3. Práctica guiada con argumentos de línea de comandos (35 min).
4. Conversación sobre reproducibilidad y dependencias (20 min).
5. Ejercicio de salida individual (20 min).

## Evidencia

Captura textual de `python --version`, entorno activo y ejecución del script con
dos valores diferentes. No se evalúa una captura de pantalla sino la explicación.

## Después de clase

Registrar el entorno usado y resolver el ejercicio indicado en el guion.
