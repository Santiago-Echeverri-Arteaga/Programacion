Contenido ampliable y no esencial. Si se perdió una clase, esta sesión se usa

2. Iteradores, `yield` y consumo perezoso (30 min).
3. Decoradores como transformación de funciones (30 min).
4. Comparación de alternativas y cierre (30 min).
