# Lista de cotejo — cierre y preparación de sustentación

- Puedo explicar entradas, salidas, contrato y unidades de una función.
- Puedo trazar un ciclo, una selección tabular y una operación sobre ejes.
- Puedo identificar claves y cardinalidad de una unión practicada con Pandas.
- Puedo justificar un tratamiento de faltantes y conservar los datos crudos.
- Puedo reproducir resultados desde el README y un entorno limpio.
- Puedo verificar un resultado con un caso conocido y explicar una tolerancia.
- Puedo distinguir defecto, error numérico y variabilidad estadística.
- Puedo interpretar un fallo de prueba y proponer el siguiente diagnóstico.
- Puedo localizar en GitHub el código, informe y commit evaluable.
- Puedo explicar mis contribuciones y la declaración de uso de IA.

Para cada punto marque evidencia disponible, insuficiente o pendiente y cite un archivo o ejercicio. No agrega requisitos al proyecto después del 5 nov.; SQL y Docker quedan fuera de esta comprobación obligatoria.
