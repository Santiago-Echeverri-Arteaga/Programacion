# Lista de cotejo de recuperación

- Puedo explicar una consulta antes de ejecutarla.
- Puedo identificar claves y cardinalidad de una unión.
- Puedo usar parámetros SQL en vez de concatenar texto.
- Puedo explicar imagen, contenedor, volumen y red.
- Puedo reproducir el entorno sin credenciales en el repositorio.
- Puedo verificar un resultado con un caso conocido.
- Puedo interpretar un error y proponer el siguiente diagnóstico.

Para cada punto marque: evidencia disponible, evidencia insuficiente o pendiente,
y cite un archivo o ejercicio concreto.
