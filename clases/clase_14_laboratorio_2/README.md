# Clase 14 — Laboratorio 2

## Propósito

Desarrollar el laboratorio de análisis de datos físicos con Python nativo y
recoger evidencia individual de comprensión.

## Antes de la sesión

Leer la [guía completa](../../laboratorios/lab02_python_nativo/README.md), crear
el repositorio de trabajo y descargar los archivos iniciales.

## Secuencia (120 min)

1. Verificación de preparación y predicción individual (15 min).
2. Adquisición o lectura de datos (20 min).
3. Implementación y pruebas por parejas (45 min).
4. Análisis físico y preparación de resultados (25 min).
5. Ejercicio de salida individual sin IA (15 min).

## Material de clase

[`verificar_entrega.py`](verificar_entrega.py) comprueba solamente la estructura
mínima; aprobarlo no garantiza la calidad científica del informe.
