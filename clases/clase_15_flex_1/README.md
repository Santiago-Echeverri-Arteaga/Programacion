# Clase 15 — FLEX 1: práctica y recuperación

Esta sesión no introduce un resultado de aprendizaje nuevo. Se usa para recuperar
una clase perdida o fortalecer Python básico antes de continuar.

## Ruta si no hay recuperación pendiente

1. Diagnóstico corto individual (15 min).
2. Selección de una dificultad común (10 min).
3. Resolución en papel y luego en código (45 min).
4. Revisión entre pares con lista de cotejo (25 min).
5. Corrección y reflexión individual (25 min).

## Material

[`practica_integrada.py`](practica_integrada.py) contiene contratos incompletos;
el estudiante implementa y documenta sin cambiar las firmas.

## Evidencia

Diagnóstico, versión corregida y nota de reflexión. La sesión puede reemplazarse
por la recuperación indicada en el registro docente.
