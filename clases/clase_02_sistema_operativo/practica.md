# Práctica — sistema operativo y procesos

1. Prediga qué líneas de `demo_entorno.py` cambiarán entre Windows y WSL2.
2. Ejecute la demo desde dos directorios y explique qué cambia y qué permanece.
3. Compare el identificador de dos ejecuciones y relacione programa con proceso.
4. Use `wsl --status` y `wsl --list --verbose` desde PowerShell para identificar
   distribución y versión, sin instalar ni eliminar componentes.
5. Clasifique tres fallos preparados por el docente como ruta, permiso o programa
   no encontrado y proponga una comprobación segura.
