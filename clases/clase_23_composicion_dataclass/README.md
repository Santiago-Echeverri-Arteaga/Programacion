# Clase 23 — Composición, invariantes y dataclass

## Propósitos

- preferir composición cuando representa la relación del dominio;
- usar `dataclass` para datos con estructura explícita;
- separar medición, instrumento y procesamiento.

## Preparación

Dibujar las relaciones entre las clases de [`experimento.py`](experimento.py).

## Secuencia (120 min)

1. Problemas de clases monolíticas (20 min).
2. Composición y delegación (25 min).
3. `dataclass`, validación e inmutabilidad (30 min).
4. Refactorización guiada (30 min).
5. Cierre individual (15 min).

## Evidencia

Modelo de tres componentes y explicación de sus responsabilidades.
