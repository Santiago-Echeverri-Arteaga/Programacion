# Sustentaciones del martes 17 de noviembre

## Propósito

Evaluar el proyecto serio mediante ejecución reproducible, defensa técnica y
comprobación individual de autoría y comprensión.

## Secuencia por equipo

1. Entrega del identificador de versión congelada.
2. Ejecución desde entorno limpio y datos identificados.
3. Pregunta física, método, validación y resultado principal.
4. Cambio pequeño solicitado por el docente.
5. Preguntas individuales sobre fragmentos y decisiones.

## Criterio de continuidad

Una demostración que no puede ejecutarse o un integrante que no puede explicar
el código activa la contingencia definida en la
[rúbrica](../../programa/rubrica_proyecto_final.md).

[`comprobar_proyecto.py`](comprobar_proyecto.py) es una revisión estructural
previa; no produce una nota automática.
