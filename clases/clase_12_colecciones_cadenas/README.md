# Clase 12 — Cadenas y colecciones

## Propósitos

- elegir entre lista, tupla, diccionario y conjunto;
- recorrer y transformar colecciones sin perder significado;
- limpiar cadenas y contar categorías.

## Preparación

Leer [`catalogar_mediciones.py`](catalogar_mediciones.py) y justificar cada
estructura usada.

## Secuencia (120 min)

1. Mutabilidad, orden y unicidad (25 min).
2. Selección de estructura según el problema (25 min).
3. Limpieza y conteo de etiquetas (30 min).
4. Práctica de modelado de datos (25 min).
5. Ejercicio de salida (15 min).

## Evidencia

Representación de un pequeño experimento con al menos tres estructuras y una
defensa breve de las decisiones.
