# Clase 35 — Pandas: tipos, faltantes y limpieza

## Propósitos

- auditar una tabla antes de transformarla;
- corregir tipos y faltantes sin borrar evidencia silenciosamente;
- conservar datos crudos y registrar decisiones.

## Preparación

Inspeccionar [`limpieza.py`](limpieza.py) y
[`auditoria_guiada.ipynb`](auditoria_guiada.ipynb); proponer una política para
cada dato faltante o inválido antes de modificar la tabla.

## Secuencia (120 min)

1. Tabla ordenada, índice y tipos (25 min).
2. Auditoría de faltantes y duplicados (25 min).
3. Limpieza reproducible (30 min).
4. Validación antes/después (25 min).
5. Ejercicio de salida (15 min).

## Evidencia

Registro de transformaciones con conteos antes/después y justificación científica.
