# Clase 08 — Tipos, operadores, asignación y entrada/salida

## Propósitos

- reconocer `int`, `float`, `bool`, `str` y `None`;
- anticipar el tipo y el valor de una expresión;
- separar lectura, transformación y presentación de datos.

## Preparación

Ejecutar [`conversion_unidades.py`](conversion_unidades.py) y anotar dos entradas
inválidas posibles.

## Secuencia (120 min)

1. Predicción de expresiones en papel (20 min).
2. Tipos, operadores y precedencia (30 min).
3. Punto flotante, unidades y formato (25 min).
4. Refactorización guiada del programa (30 min).
5. Ejercicio de salida individual (15 min).

## Evidencia

Tabla de cinco expresiones con predicción, resultado observado y explicación.
