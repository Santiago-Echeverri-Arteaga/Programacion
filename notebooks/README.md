# Notebooks

Los notebooks se reservan para exploración, visualización y narrativas de datos.
Los programas reutilizables deben migrarse a funciones en archivos `.py` y
probarse fuera del notebook.

Reglas:

- ejecutar desde un kernel limpio antes de entregar;
- mantener el orden de ejecución;
- no ocultar errores ni salidas esenciales;
- evitar datos codificados dentro de celdas extensas;
- separar cálculo, figura e interpretación;
- usar rutas relativas al repositorio.

## Pandas y SQL: cierre de octubre de 2026

En [`cierre_pandas_sql_2026/`](cierre_pandas_sql_2026/README.md) se encuentran tres
clases magistrales de 90 minutos para Colab y doce ejercicios de práctica sin nota.
El material usa datos científicos públicos (Palmer Penguins), Pandas en Colab y PostgreSQL en Ubuntu WSL2 desde VS Code. Incluye un pipeline local con Bash, Python y SQL, y deja el desarrollo del trabajo final
de convolución a cargo de los equipos.
