## Referencia de apoyo para el bloque inicial

- Nicolás Schürmann, *Ultimate Docker*, bloque introductorio de Linux. Se usa
  como orientación temática —rutas, archivos, búsqueda, flujos, tuberías y
  ejecución de scripts— y se consulta según la licencia disponible. Las
  actividades del curso son originales y la instalación de WSL2 se contrasta con
  la documentación vigente de Microsoft.

Los enlaces a las presentaciones institucionales existentes se incorporarán aquí
después de revisar permisos, vigencia y correspondencia con el nuevo cronograma.
